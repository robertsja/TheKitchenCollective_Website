# The Kitchen Collective Website

Standalone static website for The Kitchen Collective event catering.

## Files

- `index.html` - one-page site content and metadata
- `styles.css` - responsive layout and visual styling
- `script.js` - navigation, gallery filtering, lightbox and email enquiry form
- `assets/` - logo and generated hero image
- `images/` - catering gallery photos

## Hosting

This site is ready for GitHub Pages. Publish the contents of this folder as the site root.

The contact form uses a `mailto:` fallback, so it works without a backend. For stronger lead capture, connect the form to a static form provider before launch.
